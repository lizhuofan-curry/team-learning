## 这次比较什么

对同一条日志分别使用官方离线规则引擎和本机qwen3:4b：

1. 能否识别并遮盖人工标注的SSN、信用卡号、口令及诊断信息。
2. 是否保留request_id、处理阶段、失败状态和HTTP 503等排错信息。
3. 是否存在漏检、只遮盖敏感值一部分或把无关内容也遮掉的情况。

原始文本与4项标注均是合成教学材料，不读取真实日志。日志文本交给模型，标注只供本地检查，不放入提示词。单条覆盖数不是整体PII召回率，也不代表真实日志安全保证。规则与模型的设计覆盖范围不同，本例用于看清差异，不据此形成通用能力排名。
