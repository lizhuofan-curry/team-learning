# DeepTutor课程资料与使用记录

对应老师安排：每人至少负责一门真实专业课，导入日常课程资料，实际使用DeepTutor学习，并与同学交流和共享。

课程分工统一维护在根目录[分工与课程覆盖](../分工与课程覆盖.md)，按真实课表逐门核对。本人已选择数据结构、计算机网络，其余成员负责课程待实际商定；当前不能宣称覆盖全部课程。

每门课可以逐步保存：

- 来源、章节和版本清楚、允许团队共享的课件或教材片段。
- 资料导入方法、知识库配置说明（不含凭据）。
- 实际学习问题、检索引用、答案核对、帮助与错误案例。
- 其他成员获取资料并使用后的反馈、修改与复测。

先从真实一章或一份资料开始，不要求一开始做成完备课程库。资料文件存在、导入成功、回答可靠和本人学会是不同状态，分别如实记录。

DeepTutor源码分析笔记放[共同知识](../共同知识/README.md)，与课程资料通过链接关联；完整运行环境、data/settings、API密钥、私人会话及可重建的大索引不整体上传。

当前李卓凡的本地模型与嵌入链路通过测试文档验证，真实课程资料尚未完成入库；课程使用与共享记录待后续实际补充。
