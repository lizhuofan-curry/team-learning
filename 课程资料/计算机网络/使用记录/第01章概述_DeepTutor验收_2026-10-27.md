## 实际操作

使用项目原有 `.venv` 中的CLI，在DeepTutor项目根目录设置 `DEEPTUTOR_HOME` 为该项目目录。以下文件路径改为队友本机的真实路径后可重做，不在仓库保存模型密钥。

```bash
deeptutor kb create sophomore-computer-networks --doc 课件绝对路径.pptx
deeptutor kb info sophomore-computer-networks
deeptutor kb search sophomore-computer-networks '发送时延和传播时延分别由什么决定？' --format json
deeptutor run chat '仅依据第一章课件解释发送与传播时延，并计算1B数据通过1000km光纤、1Mbit/s链路的总时延，忽略处理和排队时延；标明来源。' --kb sophomore-computer-networks --language zh --format json
```

实际问答还包含“能否确定河南大学2026年本课程期末考试日期”，检验资料不足时是否说明限制。只导入这份PPTX，未把验收答案、模板、个人笔记或旧连通性测试文档混入本课程库。

## 发现的问题和限制

1. 公式上下标在纯文本中可能扁平化，例如指数变成普通数字，阅读时必须回看PPT原页面。
2. 解析结果记录76张EMF/WMF矢量图及179张超出数量/大小上限的图片未提取；知识库统计images为0。本次仅验证文字检索，未确认图示、动画或公式视觉理解。
3. 模型将82页的内容定位为83页。课件74页的二进制前缀说明也需要结合上下文理解；当前计算题按86页的Mbit/s十进制速率进行，不能泛化为所有M都等于2的20次方。
4. 首次查询状态时误用了 `kb info --format json`，该命令不支持此参数；去掉后成功读取。此操作错误与课程导入结果分开记录。
5. 未修改模型或默认知识库配置；本轮问答显式挂载计算机网络课程库。
