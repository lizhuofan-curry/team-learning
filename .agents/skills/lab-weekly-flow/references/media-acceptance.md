# 学习入口的媒体验收

用于本人要求检查Hermes语音、文章或视频可读性时。先识别Hermes实际运行位置、profile及既有工具；使用成员自己的路径与已配置环境。不因桌面客户端在本机就把处理端当作本机，也不为测试新增服务或切换账号。

## 验收顺序与范围

1. 查当前配置中的工具/脚本及其现有依赖。只读相关非秘密字段，不打印.env、Token、全量账号配置或其他聊天。
2. 使用本人指定样本。只有合成或公开系统样本时标记test，不能记录成本人阅读、学习日记或周报成果。不批量读取音频缓存，不为试用抓取大量视频。
3. 先验证输入有效，再调用现有入口，保留实际命令/函数、版本、输出、耗时和错误阶段。独立测试目录保留结果，避免SSH断线后只剩口头推测；不启动重复残留模型。
4. 将“组件存在、工具执行、取得内容、内容准确、微信端到端、本人理解”逐项列出。一次技术测试只支持实际完成的层级。
5. 只在确实发现且有针对性修复后重测。无真实素材或平台受阻时交付可执行替代入口与待验收项，不无限重试、不绕过权限或来源访问限制。

## 三类入口分别判定

| 入口 | 最小证据 | 不能当作通过 |
|---|---|---|
| 语音 | 非空可解码时长；实际模型/语言/提示；原转写；数字、单位、工具名、否定及计划/完成核对 | 只有文件或模型存在；合成WAV替代微信SILK；模型报成功但关键词错误 |
| 文章 | 原URL、真实正文段落、工具/缓存来源、已读与未读范围 | HTTP200、标题、只有链接、把首尾截断说成全文 |
| 视频 | 实际字幕/转写及时间戳；如读画面需记录实际帧/片段范围 | 标题、缩略图、播放页面、字幕请求失败后凭常识总结 |

## 语音的关键判断

- 非登录PATH缺少命令时，检查现有脚本的实际路径。全局language不是唯一依据，核对provider配置、override优先级与占位符渲染。
- 连接关闭/超时、解码失败、静音、推理失败和识别错误分开记录。无对应内核日志不能推定OOM；未收到输出不等于用户没说内容。
- 同样本可做一次有理由的单因素对照。术语提示不应包含预先期望的完整答案；修正几个词不代表数字/单位也正确。不凭一个合成样本更改默认服务。
- 识别有疑点先显示原转写，标待本人核对；按[语音排查](speech.md)保护原文与精确版本批准。测试不能升级为本人确认。

## 文章与视频的关键判断

- 工具给出指定URL的正文缓存时，可核对该文件并按需分段读。缓存有全文提取文本，只证明文本可继续访问，不代表已精读或完整解析网页图像。
- 公众号、普通网页和各视频平台逐URL验证。RequestBlocked、登录限制等按原错误类别记录，不改成“没有内容/没有字幕”。
- 优先由本人提供正文/PDF、字幕、讲义或短文件。仅字幕标“未核对画面”；未取得正文/字幕时保留资源收藏，不生成内容摘要。

## 交付

返回一张“样本与输入类型—工具—实际结果—读取范围—耗时—判定—下一步”表，附本次证据文件。配置值与真实收发分开；语音/视频受阻时文字入口可继续用。尚未提供的真实样本留待本人方便时测试，不要求为了测试马上发送语音。
