# 微信学习对话自动保存

用于本人已选择自动收集学习相关微信对话、但不想每次都说“记录学习”的情况。只改Skill描述无法保证每轮都调用采集；本实现接入Hermes官方`post_llm_call`观察事件，在成功完成当前回合后运行`scripts/auto_capture.py`。依据[官方Event Hooks说明](https://hermes-agent.nousresearch.com/docs/user-guide/features/hooks)，观察器可以收到当前用户消息和最终回复；安装前还须核对当前版本的实际字段和微信平台值。

## 数据范围与判断

- 只处理新完成的一轮：本人输入和AI最终回复；不保存完整conversation_history、内部推理、系统提示或工具输出，不扫描历史数据库。
- 默认只接收`platform=weixin`；此字段不区分同平台用户或群，必须先由网关允许名单核实只接入本人授权私聊；无法保证时先停用。其他本地/网页/群或平台需按真实网关授权和事件来源单独核对。
- 明确学习、科研、课程、代码、实验、知识库、周报等用语及技术文章链接自动保存；短期学习上下文中的“为什么/再解释/举例”等追问可以关联。无关实质话题结束追问窗口，纯寒暄跳过。识别为本地规则与30分钟上下文窗口，不额外调用模型，存在漏判/误判，不能宣称覆盖全部自然语言。
- 本人说“不要记录”“不记入周报”“私人内容”等则跳过本轮并清除追问窗口；疑似API凭据或私钥不归档并清除追问窗口。仅保留不含正文的处理状态。需要补记时仍可显式使用capture。
- 常规文字输入不改写，保存为wechat/user-original；当前版本中央STT使用双引号前缀，微信回退使用Voice transcription标记，这些输入（包括无法区分的本人引文）保留完整字段但先存assistant-summary并标注待本人核对，不进入原话归档。实际确认/纠正后再由本人另记文字并关联旧编号。AI最终回复另存assistant-summary并注明未经本人核对，关联输入编号。版本更新须重新核对语音包装格式；缺少可靠介质标记时不承诺所有转写均被识别。链接入库不表示读取正文；计划与未完成仍保留。AI回复不能作为本人已掌握、独立运行或同伴确认的证据。
- 手动CLI的capture默认从机器北京时间生成日期；旧会话传入非当天微信日期会拒绝写入，--historical仅用于本人明确要求历史补录，不作为自动重试选项。观察器本来已从回调时钟生成日期。事件date为采集日期，事发时间以原话为准；不要从本轮提及的论文或URL日期猜发生日期。每日整理时结合原话和采集状态判断，不把回顾旧事写成当天成果。

## 部署

把auto_capture.py与learning_flow.py放在同一私人工作流根目录。首次安装器会复制脚本，但不会擅自启用观察器、扩大微信授权或重启网关。

在脚本旁准备本机配置`auto_capture.local.json`：

```json
{"enabled":true,"workflow_root":"本人工作流绝对路径","platforms":["weixin"]}
```

通过当前Hermes配置API合并下列单个入口，不覆盖已有hooks和模型/语音配置。command使用当前环境的Python、脚本和配置绝对路径，包含空格时逐参数正确引用。

```yaml
hooks:
  post_llm_call:
    - command: '本人Python绝对路径 本人工作流/auto_capture.py --config 本人工作流/auto_capture.local.json'
      timeout: 5
```

Hermes对shell hook要求针对`(event, command)`授权。按本人明确选择只授权这一条已检查的命令；不要启用全局hooks_auto_accept、HERMES_ACCEPT_HOOKS或顺带授权其他脚本。保存配置和允许项前备份并校验旧版本。原有hooks不删除。此事件是观察器，不阻塞工具、不修改回复、不发送微信或邮件。

当前gateway在启动时注册shell hooks；确认需要生效时安排一次正常网关重载/重启，保留会话与账号数据。新版本支持热加载时以实际API和验证为准，不能把一个独立测试进程注册成功说成现有网关已加载。

## 验收与运行状态

先在隔离ROOT运行`scripts/test_auto_capture.py`；包括学习/文章/计划、明确不记录、无关对话、短期追问、重复回调、已手动保存原话复用，以及不采集历史/其他平台。

用Hermes真实shell hook回调适配器对隔离合成输入验证事件字段及注册方式。然后本人在微信自然提问一次（不说“记录学习”），检查`自动采集状态/YYYY-MM-DD/`的本轮状态和收件箱对应编号，再核对Mac同步结果。只有真人试用通过才能称“真实微信自动采集已验收”。合成验证不得写进日记、周报或真实收件箱。

状态仅保存日期、识别原因、会话/回合哈希和事件编号，不保存跳过回合的正文。被捕获的同一天同原话优先复用已有微信原话，不因显式capture和观察器重复落盘；周报整理仍按原话编号关联AI回复并按事项去重。

本轮失败不声称已保存。hooks观察器异常由Hermes按当前版本处理，本地状态和警告用于排错，不通过无限重试阻塞微信。关闭时将本机enabled设false即可立即停止写入，或删除该条hook配置并按实际运行方式重载；不删除原收件箱和其他钩子。
