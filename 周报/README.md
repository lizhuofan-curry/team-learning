# 三人周报归档

本目录用于三人按成员、按周保存已经确认的周报。原有邮件正文提交要求继续执行，仓库归档不能代替给老师交周报。

## 组织方式

```text
周报/
├── 李卓凡/                  # 已归档四期原文
│   └── 姓名YYYY-MM-DD_YYYY-MM-DD_周报.md
├── 胡博/                    # 四期周报及来源说明
│   └── 姓名YYYY-MM-DD_YYYY-MM-DD_周报.md
├── 王宝糠/                  # 五期周报及来源说明
│   └── 姓名YYYY-MM-DD_YYYY-MM-DD_周报.md
└── 附件/                  # 周报引用图片
```

每人以自己的账号维护自己的周报。正文保留本人确认内容与真实日期；需要更正时在后续提交中说明，不把后做的实验倒填为当周成果。历史周报保留其当时状态，不为了符合当前进度整体改写。

李卓凡四期周报由本人明确要求团队归档，原样复制并保留图片；Git提交记录说明由其账号归档，不冒称同伴已经阅读。

胡博于2026-10-29确认署名及最后一期截止日期为10月25日，并授权上传个人库 `01_Daily` 中的四份周报。正文的学习结果与待办保留当时记录；本次整理更正末期标题日期、处理图片链接，并将未上传的个人库双链保留为文本。原文件对应关系、引用范围与核对说明见[胡博的周报入口](胡博/README.md)。

王宝糠五期周报（9/28—10/31）由本人于2026-10-31提供桌面存档并要求归档；本次只按命名规范调整文件名，正文未改动。第3—5期正文提到的实验报告、笔记、代码与演示视频等附件未随本次材料提供，仓库内没有对应文件。对应关系与核对说明见[王宝糠的周报入口](王宝糠/README.md)。至此三人周报均有归档。
