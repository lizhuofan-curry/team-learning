# 三人团队学习知识库

用于三人共享Agent实验资料、课程学习资源与经过核对的共同知识。GitHub仓库保持Private，每位成员用自己的账号提交，Obsidian打开各自clone得到的本地目录。

## 当前状态

- 三人小组已确定；另两位成员姓名与GitHub账号待补充。
- 本仓库完成基础目录和协作说明准备，尚无三人共同提交、互审或接收方复测记录。
- 初始化说明由AI辅助整理，不作为成员个人心得或受禁用大模型约束的读后感。
