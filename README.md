# 三人团队学习知识库

共同整理 Agent Book 实验、专业课程资料、DeepTutor 学习记录、共享笔记和每周总结，让每个人的学习成果能够被队友找到、核对和使用。

**找资料 → 实际学习 → 提交记录 → 同伴审阅 → 吸收进个人知识库。**

[资料目录](#资料目录) · [参与共建](#参与共建) · [Agent 整理与 PR](#使用-agent-整理资料并提交-pr) · [成员与课程分工](分工与课程覆盖.md) · [讨论区](https://github.com/lizhuofan-curry/team-learning/discussions)

| 你想做什么 | 从这里开始 |

## 参与共建

1. **确定放置位置**：先查看已有内容，按[文件组织规范](协作指南/文件组织规范.md)选择课程、实验或主题目录，避免重复上传。
2. **在自己的分支修改**：更新资料及所属 README；新增课程或项目入口时同步[资源索引](资源索引.md)。课程分工只在[分工表](分工与课程覆盖.md)维护。
3. **说明来源和实际进度**：写清资料来源、本人完成的工作、未确认部分和需要队友帮助核对的内容。
4. **检查并提交 PR**：按[PR 模板](.github/pull_request_template.md)描述改动，由另一位成员留下具体审阅意见，再合并。
5. **获取并吸收更新**：拉取合并后的内容；进入个人知识库时引用团队文件及版本，结合自己的实践整理理解。

首次操作可跟随[Git 协作入门](协作指南/Git协作入门.md)。贡献包含资料整理、审阅、复现、纠错及实际帮助，不只计算提交次数。共享边界与协作方式见[协作约定](协作指南/协作约定.md)。

## 使用 Agent 整理资料并提交 PR

仓库已有[团队资料整理 Skill](.agents/skills/team-learning-materials/SKILL.md)，可辅助分类、命名、维护链接和入口、检查改动并准备草稿 PR。操作说明见[Agent 资料整理指南](协作指南/Agent资料整理指南.md)。

可以把以下提示词连同指定资料交给支持读取仓库文件的 Agent：

```text
请按本仓库 .agents/skills/team-learning-materials/SKILL.md 整理我指定的资料：
1. 读取协作约定、文件组织规范、目标目录说明和 PR 模板。
2. 查重，确认所属课程、实验或主题，保留真实来源与核对状态。
3. 整理文件名和附件，更新所属 README；新增入口时更新资源索引。
4. 运行布局与链接检查，核对本次差异，排除凭据及未授权共享的内容。
5. 在独立分支提交，创建或更新本任务的草稿 PR。
6. 说明检查结果和待同伴核对的内容，不自动合并。
```

Agent 整理、程序检查、本人理解和同伴审阅分别记录。实验区分本人真实运行、离线复核和教材参考；课程区分资料归档、成功入库、真实使用与同伴复测。

## 仓库检查

在仓库根目录运行：

```bash
python3 scripts/check_layout.py .
python3 scripts/check_docs.py .
```

[GitHub Actions](https://github.com/lizhuofan-curry/team-learning/actions)会在 PR 和主分支更新时执行检查。现有脚本检查目录、命名、文档链接与附件；知识是否正确、引用是否支持结论，仍需提交者与同伴核对。

新增内容可使用[课程入口模板](协作指南/模板/课程入口模板.md)、[共享笔记模板](协作指南/模板/共享笔记模板.md)或[DeepTutor 使用记录模板](协作指南/模板/DeepTutor使用记录模板.md)。完整维护入口见[协作指南](协作指南/README.md)。
