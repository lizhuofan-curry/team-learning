## 为什么选了知识库还要核对检索

选择知识库会进入本轮请求上下文，并影响可用工具；它不保证模型每轮都调用`rag`，更不证明模型回答正确。需要同时看：本轮选中了哪一个库、实际是否检索、返回何种证据、回答是否与原材料一致。

## 三个容易误解的分支

1. **无库名不走默认库。** `rag_search`对空`kb_name`直接抛`ValueError`，包括管理员；不偷偷检索示例库。
2. **PageIndex不走普通RAG。** 聊天工具组合会排除只走PageIndex的库；`RAGService.search`遇到PageIndex还会返回`reasoning_as_retrieval_required`，不能直接套LlamaIndex路径。
3. **检索结果不等于看过图片。** `RAGTool`根据视觉支持处理原始图像；缺少像素读取时保留说明，文本命中不能证明图表理解正确。

## 可复核的隔离练习

在自己的DeepTutor源码根目录，用Python3.11及以上运行下面代码。它从文件提取真实`rag_search`函数，仅替换服务与访问解析为假对象，不导入项目设置、不读课程和凭据、不联网。验证的是参数和调用边界，不能替代真实RAG验收。

```python
import ast
import asyncio
from pathlib import Path
from types import ModuleType
from typing import Optional
from unittest.mock import patch

tree = ast.parse(Path("deeptutor/tools/rag_tool.py").read_text(encoding="utf-8"))
function = next(n for n in tree.body if isinstance(n, ast.AsyncFunctionDef) and n.name == "rag_search")
calls = []
class FakeRAGService:
    def __init__(self, **kwargs):
        calls.append(("init", kwargs))
    async def search(self, **kwargs):
        calls.append(("search", kwargs))
        return {"answer": "模拟结果", "sources": []}

namespace = {"Optional": Optional, "RAGService": FakeRAGService}
exec(compile(ast.Module(body=[function], type_ignores=[]), "rag_search-isolated", "exec"), namespace)
search = namespace["rag_search"]
access = ModuleType("deeptutor.multi_user.knowledge_access")
access.resolve_for_rag = lambda name: None
with patch.dict("sys.modules", {access.__name__: access}):
    for args in ({"query": " ", "kb_name": "course"},
                 {"query": "单位换算", "kb_name": ""},
                 {"query": "单位换算", "kb_name": "unavailable"}):
        try:
            asyncio.run(search(**args))
        except ValueError:
            pass
        else:
            raise AssertionError("invalid input unexpectedly accepted")
    assert calls == []
    result = asyncio.run(search(query=" 单位换算 ", kb_name=" course ", kb_base_dir="isolated-fixture"))
assert calls[-1][1]["query"] == "单位换算"
assert calls[-1][1]["kb_name"] == "course"
assert result["answer"] == "模拟结果"
print("4个隔离场景通过；未调用真实模型或知识库")
```
