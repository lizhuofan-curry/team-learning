## 两种时延怎样区分

发送时延由数据长度和发送速率决定，表示把这些比特全部送入链路需要的时间。传播时延由链路长度和信号传播速率决定，表示信号通过链路需要的时间。对应课件78—80页。

```text
发送时延 = 数据长度(bit) / 发送速率(bit/s)
传播时延 = 链路长度(m) / 传播速率(m/s)
```

提高发送速率会减小发送时延；不能据此说电磁信号在同一介质中的传播速率也提高。课件84页专门提醒这个区别。

## 用课件例子核对单位

课件85—86页讨论1B数据通过1000km光纤链路的情况，假设忽略排队和处理时延，传播速率取200000km/s。

```text
发送速率1Mbit/s：8 / 1000000 s = 0.008 ms
传播时延：1000 / 200000 s = 5 ms
总时延：5.008 ms
```

若只将发送速率提高到1Gbit/s，总时延约5.000008ms。这个小数据例子中传播时延占主导，不能将发送速率的1000倍提升当成总时延同倍下降。
