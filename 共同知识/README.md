# 共同知识与共享笔记

保存愿意共享的个人学习笔记、DeepTutor源码分析、概念解释、方法比较与纠错。每份笔记标明作者、日期、来源和核对状态；共享到这里不自动表示三人已达成共识。

DeepTutor源码分析可结合实际阅读记录说明：分析的项目版本、文件/函数、输入输出、信息流、工具调用、错误处理，以及静态阅读和亲自调试分别做到哪里。需要时链接实验或课程使用记录，不把辅助生成的讲解当作本人已经掌握的证明。

临时或未经核对的笔记可以共享，但明确标记“初稿/待核对/个人理解”；经同伴审阅或实测支持后，再补充核对人、证据和适用范围。由AI辅助的部分注明来源，不冒充本人结论。

微信群、大模型或[Discussions](https://github.com/lizhuofan-curry/team-learning/discussions)中的重要结论，经过核对后整理成这里的Markdown文档并引用来源。个人知识库吸收时保留团队文件链接和版本，再结合自己的实践形成理解。

当前仅有组织说明，没有提前填写三人共同学习结论。
