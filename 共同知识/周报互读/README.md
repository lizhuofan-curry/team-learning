## 写法约定

- 引用队友的观点时写明出自哪一期、哪个文件，便于回查；只读周报、未读实验记录时，把引用的数字标为「转述」。
- 只写读到的内容与自己的判断，不替队友总结他们没写过的结论，也不把某个人的归纳写成三人的共识。
- 读后感属于个人总结，可用大模型辅助提供思路和组织表达，但需本人确认；AI 辅助范围在文首写清楚。
- 从中引出、尚未动手的路径单独列一节，完成后再补带运行记录的笔记，不把计划写成已完成。
