# 实验资料

[Agent Book团队实验记录](AgentBook/README.md)已直接保存李卓凡的29份主记录及必要引用材料，可在本仓库阅读全文，不用跳转个人项目查看记录正文。

不同成员做同一个实验时，按`项目/第NN章/实验编号/本人GitHub账号/实验编号_账号_实验记录.md`保存；代码和附件在本人目录内部，不覆盖其他成员。只建立有实际材料的目录，入口由项目、章节、实验逐层汇总，不在根目录散放副本。详见[文件组织规范](../协作指南/文件组织规范.md)与[实验记录模板](../协作指南/模板/实验记录模板.md)。

保留目的、运行条件、实际输出、失败、分析和未完成项；导入已有记录不等于重新运行，也不表示其他成员已复现。大型数据集、模型与运行环境不复制进团队库。
