# Agent Book实验资料

保存学习《深入理解AI Agent》时完成的实验与实验记录。按成员、章节或实验编号组织，每项记录能找到以下信息即可：目的、输入与运行条件、关键代码、实际结果、失败与处理、本人分析和剩余范围。

区分本人真实运行、离线结果复核、教材参考和未执行计划；使用替代模型、缩小样本或改写代码时明确说明。保留原始输出，不把修正后的解释伪装成模型原回答。

较大的完整代码项目继续在各自开发仓库维护，团队库记录仓库地址、对应提交、运行入口和关键结果。大型数据集、权重、虚拟环境和密钥不复制进团队库。

李卓凡现有项目：[ai-agents-book-learning](https://github.com/lizhuofan-curry/ai-agents-book-learning)。本目录尚未搬入具体实验文件，也不表示其他成员已复现。
