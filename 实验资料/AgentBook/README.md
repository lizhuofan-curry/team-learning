## 怎样新增自己的记录

按`第01章/1-1/本人GitHub账号/1-1_账号_实验记录.md`保存；代码、截图、日志与补充分析保留在本人目录内部。修改同一成员的主记录时依靠Git留历史，不新建“最终版”副本。更新该实验README的成员表，由队友通过PR核对。详细规则见[文件组织规范](../../协作指南/文件组织规范.md)。

## 来源与读取范围

来源为本人AI_Agents_Book项目的既有记录，固定提交`162191203b31ee701f66a1b55b334915f31626e0`，原位置和原文SHA写在各份主记录开头。原项目文件保持不变，归档副本只增加来源说明并修正相对链接；运行日期、失败和原始结论沿用正文，导入不算重新运行。

本次仅复制主记录及它们实际引用的说明、关键代码、结果和图片，不复制备份目录、虚拟环境、模型权重或个人配置。支持材料保持原文件名和内部结构；成员目录下的代码属于证据归档，不保证脱离原项目依赖后可直接运行。历史Windows本机路径是当时运行条件，不是队友应照抄的部署路径。

日志脱敏和提示注入实验中的密码、SSN或secret字段属于原记录标明的教学/构造样例；不能据此填写真实凭据。实际运行、离线复核、教材参考、AI辅助解释和未完成计划仍分别保留；同伴复测只有真实发生后才登记。
