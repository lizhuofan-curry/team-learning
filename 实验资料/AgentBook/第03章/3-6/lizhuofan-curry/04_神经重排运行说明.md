准备与实测日期：2026-10-18。用户已完成27对、5批正式重排，未截断，保存输入、分数和指标核对通过；Recall/Precision/MRR@5=1/0.32/0.9。见[最终小结](05_重排结果与实验3-6小结.md)。下文保留本步配置与运行方法，不需要重复运行。

## 这次比较什么

上一轮两种融合的Recall/Precision/MRR@5均为1/0.32/0.9，稠密基线为1/0.32/1。`training neural networks`的doc_4因两路共同命中而升至第一，把首个标注相关doc_11推到第二。本次观察交叉编码器重新判断查询与文档关系后，排名是否改变，不预设一定改善。

流程为：读取已核对融合结果 → 对每条查询的既有候选文档逐一评分 → 按新分数排序 → 取前5与原基线比较。

融合关注两路排名与分数；交叉编码器直接共同读取查询和文档文本，为每个配对输出一个相关性logit。logit不是概率，也不与BM25、余弦或RRF分数直接相加。本步不生成自然语言回答，不使用Qwen或DeepSeek。

## 固定配置

| 项目 | 配置 |
| --- | --- |
| 语料、查询和标注 | 原12篇英文文档、5条查询，不改标注 |
| 候选 | 已保存的RRF完整候选并集，分别5/5/5/7/5篇 |
| 评分预算 | 27个查询—文档配对，按每条查询一批，共5批前向，无预热 |
| 模型 | cross-encoder/ms-marco-MiniLM-L6-v2 |
| 模型固定版本 | 233902d25c440f23af6f7d6e94d2946bac0bee0a |
| 设备与精度 | CPU、float32、4线程、eval/no_grad |
| 分词 | 查询与文档配对，最长512 token，按批补齐；保存实际长度及截断数 |
| 输出 | 原始logit、完整候选排名、前后名次、Top-5和共同指标 |
| 平分处理 | 稳定排序，保留原RRF候选顺序 |
| 网络与云端 | 均0，无下载、回退或自动重试 |

相关标注不送给模型，模型输入只有查询和原始文档正文。标题、文档ID、旧分数也不参与模型评分。RRF与加权融合本来拥有相同候选集合，本次对该集合只评分一次，复用新排序与两种融合比较，不重复做两份推理。

保留完整并集很重要：第四题有7篇候选，不在重排前再截成5篇；模型可从这7篇中选择最终前5。但并集以外的文档仍不能被找回。每条查询的候选覆盖率与最终Recall分开理解。
