# 多Agent复查：Skill入口、接入与配置

## 范围与分工

本轮按成员请求，由三个独立子Agent分别审查：README/AGENTS发现入口、两套Skill的新成员与已有库前向试用、工作流脚本的隔离工程复现。主Agent集成修复、补回归测试并验证仓库。模拟数据仅存在隔离临时目录，未替成员批准真实周报、未修改成员原始资料或微信凭据。

开始前同步远端已有的旧稿重传保护修复6d0b93c，未用较旧的本地代码覆盖。代码审查、隔离模拟、Windows CI、成员实用和同伴审阅分别记录。

## 发现与修复

| 实际问题 | 处理结果 |
|---|---|
| 已有个人库重新配置会覆盖自选周报目录 | 保留obsidian_reports，只有显式--obsidian-reports才更改；平铺库未选择目录时提示，不强加wiki层级 |
| 固定单备份阻断正常连续配置 | 保留首版快照，其他历史按内容哈希保存；本地/云端设置及后续团队接入可连续执行 |
| 更换个人库后原话仍可能写旧库 | 未明确原话与周报新目标时拒绝迁移且配置不变；明确选择后新素材只进入新位置 |
| 首条test确认阻挡后续真实确认 | 测试本身仍不能归档；本人明确确认当前版本后另存真实记录，不覆盖test，附加记录也能同步 |
| README没有两套Skill的清楚使用入口 | 增加用途表、已有库/新成员/日常周报三组提示词、本地/云端与Windows入口 |
| 缺少仓库根Agent路由 | 新增根AGENTS.md，按任务指向三套技能；不保证所有Agent仅打开网页即可自动发现 |
| 通用Agent没有Codex对话工具 | 明确可使用本人提供的摘录和Hermes素材，报告未覆盖范围，不编造全天会话采集 |
| 拉取新版后安装冲突缺少说明 | 增加维护指引：比较已安装与目标版本，保留定制与运行配置，不删除收件箱重装 |
| 本机配置和未审核材料可能误入团队Git | gitignore新增本机配置、历史备份、收件箱、待审核/确认及运行状态的忽略规则 |

子Agent复验确认：旧库原笔记哈希保持、既有自选归档目录保持、连续配置成功、换库拒绝/明确选择的正反路径有效；测试确认本身和其跨节点导入均不能当作真实批准，后来明确的本人确认才能支持归档。

## 本地验证

从仓库根目录执行：

```text
python .agents/skills/lab-weekly-flow/scripts/test_learning_flow.py
python .agents/skills/lab-weekly-flow/scripts/test_portable_cli.py
python -m unittest discover -s tests
python scripts/check_layout.py .
python scripts/check_docs.py .
git diff --check
```

集成时23项核心测试、12项CLI集成测试、44项仓库检查器测试通过；布局、文档链接与diff空白检查通过。新增本报告后由提交者再次检查链接和布局。Windows结果以本轮最终提交对应CI为准，不复用之前提交的成功结果。

## 对队友的使用结果

克隆后从README或AGENTS进入。支持项目Skill的Agent可发现.agents/skills；不支持时复制README提示词并明确读取文件。每人维护自己的个人库和工作流，只克隆共同团队远端，不另造每人一个团队仓库。个人素材按明确选择共享，不能把所有日记自动上传团队。

## 仍需成员实际参与

本轮不证明全队已完成微信扫码、真实语音、多媒体、源码学习或互审。完整每日23:00整理和本人真实周报确认仍按实际运行验收；不得把本轮Agent复查统计成成员之间的实质审阅。PR不自动合并，工作分支同步不等于已经进入主线。
